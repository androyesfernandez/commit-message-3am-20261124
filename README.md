## The message (91 chars)

> fix: deleted the database to fix the database, currently restoring from a screenshot I took

## Why it wins

Two beats in one flat, deadpan line: a self-inflicted circular disaster (deleted the database *to fix* the database) and an absurd recovery plan (restoring from a screenshot). No punchline punctuation, no winking — it reads exactly like a real 3 AM commit written by someone too tired to lie about what happened.

## How to run

```sh
node main.ts
```

Writes the message to `/output/entry.txt` with no trailing newline, then reads it back and verifies it is byte-identical, throwing on any mismatch. The message is guarded to 1–200 chars and a single line.
